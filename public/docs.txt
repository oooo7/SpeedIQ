Key Technical Challenges
1. 24-Hour Window Rule

WhatsApp allows free-form messages only within 24 hours of customer's last message
Outside 24 hours: must use approved templates
Solution: Track last inbound message timestamp per contact

2. Rate Limiting

WhatsApp limits messages per second (80/sec for verified)
Daily limits based on tier (1k/10k/100k unique recipients)
Solution: Message queue with throttling

3. Webhook Reliability

Webhooks can fail or come out of order
Need idempotency (don't process same message twice)
Solution: Use message IDs, check for duplicates

4. Real-time Chat

Need instant message delivery to UI
Solution: Supabase realtime subscriptions or websockets

5. Media Handling

Images/documents sent by customers need to be downloaded from WhatsApp
WhatsApp media URLs expire after 5 minutes
Solution: Download immediately and store in your own storage
